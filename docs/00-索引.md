## 当前重点

1. 核心仍然是 `core + CLI + MCP + hosts`。
2. 前端可视化放最后做，只消费稳定接口。
3. 每轮开发前检查 `[[IMPLEMENTATION_PLAN]]` 和 `[[ISSUES_TODO]]`。
4. 每轮开发后必须做测试，并把新问题写回笔记。

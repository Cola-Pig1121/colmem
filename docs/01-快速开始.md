# 快速开始

## 目标

在本地启动 `colmem` 的最小工作流：初始化状态、索引项目、查询、查看 facts、连接 MCP。

## 环境

- Rust workspace 根目录：`D:\Code\Mempalace\mempalace\colmem`
- 主要入口：
  - `crates/colmem-core`
  - `crates/colmem-cli`
  - `crates/colmem-mcp`
  - `crates/colmem-hosts`

## 常用命令

```powershell
cargo test
.\scripts\verify.ps1
cargo run -p colmem-cli -- init
cargo run -p colmem-cli -- ingest
cargo run -p colmem-cli -- query "hybrid retrieval" codex builder
cargo run -p colmem-cli -- facts list active 2026-04-10
cargo run -p colmem-cli -- mcp serve
```

默认推荐先跑 `.\scripts\verify.ps1`。

- 它现在走稳定的逻辑验证路径，核心是 `cargo test`
- 如果需要尝试 fresh 二进制烟测，再显式加 `-LiveBinary`
- 当前 `-LiveBinary` 仍可能因为 Windows `os error 5` 失败，这属于本地构建路径问题，不代表核心逻辑回归

## 当前已知限制

> [!warning]
> 当前 Windows 环境下，`cargo run` 有时会报 `os error 5`。这不是逻辑缺陷，而是本地构建路径占用问题。详细记录见 [[04-开发笔记/踩坑记录]]。

# 开发规范

## 目的

这里约束 `colmem` 的接口、组件边界、命名和页面实现方式，避免后续文档、代码和前端各讲各的。

## 默认原则

- 术语优先用工程语义，不直接复用旧 palace 隐喻。
- 接口先稳定，再做 UI。
- 文本证据永远优先于摘要。
- facts 负责约束，不替代 evidence。

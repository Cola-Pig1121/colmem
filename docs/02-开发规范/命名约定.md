# 命名约定

## 术语

- 用 `Workspace` 表示全局运行域。
- 用 `ProjectScope` 表示单项目接入层。
- 用 `Space`、`SpaceTree`、`SpaceLink` 表示语义空间。
- 用 `Fact` 表示可带时态的结构化事实。
- 用 `ContextPack` 表示回答前组装的上下文。

## Rust 代码

- 类型名用 `PascalCase`。
- 函数和模块用 `snake_case`。
- 枚举值尽量和对外字符串一一对应，例如 `FactQueryScope::Active -> "active"`。

## 文档

- 中文标题优先，方便快速检索。
- 文档文件名按主题分组，索引统一叫 `index.md`。
- Obsidian 内部链接优先用 `[[wikilink]]`。

## 避免

- 不要重新引入 `wing / hall / closet / drawer` 作为实现层术语。
- 不要让同一概念同时出现多个英文缩写。

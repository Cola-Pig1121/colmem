# 组件使用

## workspace crates

- `colmem-core`
  - 领域模型、ingest、retrieval、facts、harness、storage、MCP 核心处理。
- `colmem-cli`
  - 本地操作入口，负责命令分发和状态落盘。
- `colmem-mcp`
  - 标准 MCP server 二进制壳层。
- `colmem-hosts`
  - 宿主描述、兼容性和接入元数据。

## core 内部模块

- `agent.rs`：agent profile、persona、evolution patch。
- `capability.rs`：统一 capability 模型与注册表。
- `facts.rs`：时态 facts、audit、scope、evidence ids。
- `retrieval.rs`：hybrid retrieval 主链路。
- `rerank.rs`：规则化 rerank 与 fact-aware boost。
- `harness.rs`：高层查询编排与 context pack。
- `mcp.rs`：MCP tool surface。
- `storage.rs`：workspace state 持久化。

## 使用原则

- 新能力先考虑落在 `colmem-core`，不要直接写进 CLI。
- CLI 只编排，不承载核心规则。
- UI 以后只消费现有接口，不重复实现业务逻辑。

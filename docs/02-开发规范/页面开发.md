# 页面开发

## 当前定位

前端是可选可视化层，不是业务核心。默认放在最后做，推荐使用 Vue 3。

## 页面职责

- 展示 workspace、project、agent、facts、capabilities。
- 展示 retrieval plan、context pack、audit events。
- 提供调试入口，但不直接实现检索、facts 或 evolution 逻辑。

## 页面必须遵守

- 所有数据都来自 backend。
- 不在页面层重写评分规则。
- 不把 state 逻辑拆成前端私有版本。

## 预留页面

- Workspace Overview
- Project Inspector
- Agent Inspector
- Fact Explorer
- Retrieval Debugger
- Capability Registry

## 联调原则

> [!tip]
> 页面开始前，先稳定 CLI/MCP 输出；页面只消费稳定字段，不先行定义协议。

# 分包策略

## 原则

- 核心逻辑进入 `colmem-core`。
- 宿主壳层尽量薄。
- 文档、测试和运行时数据不混在一个 crate 里。

## 当前拆分

### `colmem-core`

- 领域模型
- 存储
- 检索
- facts
- harness
- MCP 请求处理

### `colmem-cli`

- 命令行入口
- 面向人类和脚本的运维接口

### `colmem-mcp`

- stdio MCP 二进制
- 连接外部 agent 宿主

### `colmem-hosts`

- 宿主枚举
- capability 兼容性
- host metadata

## 后续可能新增

- `colmem-web`
- `colmem-facts-sqlite`
- `colmem-retrieval-vector`

## 拆分标准

- 只有当边界稳定、复用明确时再拆新 crate。
- 不为“看起来更模块化”而过早拆包。

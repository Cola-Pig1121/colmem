# 目录结构

```text
colmem/
├─ crates/
│  ├─ colmem-core/
│  ├─ colmem-cli/
│  ├─ colmem-mcp/
│  └─ colmem-hosts/
├─ docs/
├─ .colmem/
├─ Cargo.toml
└─ README.md
```

## 说明

- `crates/`：主 workspace。
- `docs/`：本地记忆文档、规范、架构、开发笔记。
- `.colmem/`：workspace state 持久化目录。
- `target/`：Rust 构建输出，不作为设计依据。

## 文档约束

- `docs/00-索引.md` 是总入口。
- `docs/02-开发规范/` 存规则。
- `docs/03-架构设计/` 存系统设计。
- `docs/04-开发笔记/` 存动态经验与坑。
